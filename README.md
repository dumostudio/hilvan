# Hilván

Plataforma de patronaje tipo Canva: patrones para coser, directo en el navegador.

## Qué es
Hilván es para quienes empiezan a coser por necesidad y quieren hacer su propia ropa sin saber patronaje. Elige la prenda, pone sus medidas y descarga el patrón listo para imprimir y coser.

## Estado del MVP
- Un solo archivo, sin login, una prenda lista: falda de tablones.
- Tallas con selector (la cintura se triplica para los tablones).
- Aún no está publicado en internet.

## Qué sigue
1. Definir las 10 prendas infantiles que irán como "próximamente".
2. Publicar el MVP con la falda + las 10 como "próximamente" para medir visitas y descargas.
3. Recibir reseñas y seguir con ropa de bebé y patrón de osito para peluches de recuerdo.
4. Meta final: crear patrones desde cero y que las patronistas vendan los suyos.
